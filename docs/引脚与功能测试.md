# KF56-10 第三题接线与功能测试

工程已实现题目中的基本功能，以及双通道、1～5 次谐波与 THD、相位差、自动量程。实板已通过串口收发、批量指令、单双路切换和变更采样率测试。已知信号的频率、幅值、相位和谐波也在板上用合成样本验证过。现场仍需用真实信号发生器测模拟输入精度、用 VOFA+ 看波形、实际操作触摸屏并观察是否撕裂。

## 先接这几根线

| 用途 | 开发板端 | 怎么接 |
|---|---|---|
| CH1 模拟输入 | **P8-29 → PA5 → ADC1_IN5**，网名 `STM_ADC` | 接信号发生器 CH1 输出。外接时断开 J4 上将 `STM_ADC` 接往 `R_ADC`、`P_TOUCH` 或 `STM_DAC` 的跳帽。 |
| CH2 模拟输入 | **P8-32 → PA6 → ADC2_IN6**，网名 `DCMI_PCLK` | 接信号发生器 CH2 输出。先从 `P2` 拔下摄像头。`P8-30` 是 `PA4`，接线时按 `P8-32` 数针位。 |
| 公共地 | 例如 **J7-1 → GND** | 两路信号发生器输出都与板子共地。原理图中 J6、J7 各自的 1、3、5 脚为 GND，按板上 1 脚标记确认方向。 |
| Mac 串口 | **USB3** → CH340C → USART1 | 用可传数据的 USB 线。`P12` 保留 **1–2** 和 **3–4** 两只跳帽。`P12-1` 是 `PA10 / RX`，接 CH340C 的 TXD。`P12-3` 是 `PA9 / TX`，接 CH340C 的 RXD。 |
| 板载电位器 | J4 的 `R_ADC ↔ STM_ADC`，读 PA5 | 先拔掉 PA5 上的外部信号，再接回这一对跳帽。拧旋钮时，屏幕或 `MEAS?` 的直流值应跟着变。 |
| 烧录与调试 | JTAG1 的 `7 → PA13 / SWDIO`、`9 → PA14 / SWCLK` | 已连接的 ST-LINK 可继续用。`JTAG1-15` 为 `NRST`，`JTAG1-4` 为 GND，`JTAG1-1/2` 是目标 3.3 V。目标电压参考与供电按实际探针标记连接。 |

接入 PA5、PA6 前，核对偏置和峰峰值，用参考示波器确认最低和最高电压。每路电压都必须落在 **0～3.3 V** 内，对称波形的上下峰值可用 `偏置 ± Vpp/2` 计算。若发生器设为 `50 Ω` 负载而板上是高阻输入，实际幅值可能与面板设定不同。按实际负载配置发生器，并以实测电压为准。首次用 **1 kHz 正弦、1.00 Vpp、1.50 V 偏置**即可。

### 板内已经连好的线

| 功能 | MCU 引脚和板内接法 |
|---|---|
| ADC 的采样时钟 | TIM2 使用片内更新事件 `TRGO` 同时触发 ADC1、ADC2，采样率为 200 kHz。DMA2 Stream0 从公共数据寄存器搬数据。这部分在芯片内连通，无需从定时器引脚接线。 |
| TFT 控制线 | `PB15 / BL → LCD1-3`、`NRST → LCD1-8`、`PD5 / NWE → LCD1-10`、`PG12 / NE4 → LCD1-12`、`PF12 / A6 → LCD1-14`、`PD4 / NOE → LCD1-16`。 |
| TFT 数据线 D0～D3 | `PD14、PD15、PD0、PD1 → LCD1-32、30、28、26`，各组按顺序一一对应。 |
| TFT 数据线 D4～D7 | `PE7、PE8、PE9、PE10 → LCD1-24、22、20、18`。 |
| TFT 数据线 D8～D12 | `PE11、PE12、PE13、PE14、PE15 → LCD1-17、19、21、23、25`。 |
| TFT 数据线 D13～D15 | `PD8、PD9、PD10 → LCD1-27、29、31`。 |
| 电阻触摸屏 | `PB0 / T_SCK → LCD1-7`、`PF11 / T_MOSI → LCD1-9`、`PB2 / T_MISO → LCD1-11`、`PC13 / T_CS → LCD1-13`、`PB1 / T_PEN → LCD1-15`，按下时 `T_PEN` 为低电平。 |
| 触摸校准保存 | 板载 EEPROM 的 I²C 使用 `PB8 / SCL`、`PB9 / SDA`。屏幕 `CAL` 保存四点校准结果。 |

## 上电后的准备

1. 先确认烧入的是本项目正式固件。将 LCD、信号源和 USB 串口接好。首次演示开始前先打开桥接和 VOFA+，正式演示期间保持 USB 串口连接，按题目要求一次上电操作到底。CH340C 重新开串口时可能触发板上的自动复位电路。
2. 如果桥接已在运行，直接让 VOFA+ 用 **TCP 客户端**连接 `127.0.0.1:9000`，协议选 **JustFloat**，给波形控件绑定 CH1。桥接需要启动时，按 [README 的 Mac 步骤](../README.md#mac-上的-vofa) 执行。
3. 发送 `STAT?`，确认返回 `FS=200000`、`LCD=9341`。连续两次查询应看到 `MS`、`ADC` 增长。串流期间观察 `ADCERR`、`DMADROP`、`TXDROP`、`RXERR` 和 `LCDMISS` 是否增加。发送区使用 ASCII，每条命令以换行结尾。
4. 若屏幕显示校准十字，依次点准并松开四个十字。校准后试点 `TIME`，用 `CONF?` 核对设置是否改变。也可以主动点屏幕上的 `CAL` 或发送 `CAL`。

## 基本功能逐项测试

### 1. ADC 采集与 VOFA+ 波形

**用到的引脚**为 `P8-29 / PA5`、`GND`、`PA9 / PA10`，通过 USB3 接 Mac。

1. 发 `MODE AUTO` 和 `STREAM 1`。先用 1 kHz 正弦确认能看到波形，再测 100 Hz、1 kHz、5 kHz、20 kHz。用 0.20 Vpp 和 2.00 Vpp 检查幅度范围，用 1.00 V 和 2.00 V 检查直流偏置范围，各组合先核对实际最高和最低电压。
2. 单路桥接默认每个显示点间隔 **5 µs**，其中一半为插值。使用 `--raw-points` 时每点间隔 **10 µs**。调节 VOFA+ 显示窗口，使高低频分别能看见几个周期。
3. **通过标准**为频率改变后能看出对应周期，整段波形连续，肉眼可见的断帧、缺段和台阶状失真都没有出现。测试期间用 `STAT?` 核对错误计数。

### 2. 串口命令和非法输入

**用到的引脚**为 USART1 的 `PA9 / TX`、`PA10 / RX`，经 P12、CH340C、USB3。想同时看波形时保持 CH1 接入。

| 发送 | 应看到的结果 |
|---|---|
| `RUN`、`STOP`、`SINGLE` | 恢复、冻结、武装一次捕获，操作有效时回 `OK`。在单次模式下 `RUN` 会重新武装。 |
| `TRIG 1.5`、`EDGE FALL` | 触发电平设为 1.50 V，边沿切到下降沿。用 `CONF?` 和屏幕交叉检查。 |
| `TB 500us`、`VDIV 250mV` | 运行态下改成 500 µs/格、250 mV/格。触摸切档后再发 `CONF?`，检查两边同步。 |
| `MEAS?`、`WAVE?` | 返回测量读数和一帧 240 点的快照。按 README 启用 `--wave-file` 时，可查看 `build/capture.csv`。正常波形连续串流期间也可查询。 |
| `BOGUS`、`TRIG -1`、`TB 77us`、连续 300 个 `X` | 回 `ERR`。发送前后比对 `CONF?`，设置应相同。若先发了无换行的 300 字节，发一个换行结束这一行，再发合法命令。 |

可在 Mac 终端运行 `python3 -c 'print("X" * 300)'` 生成一行测试字符，再复制到串口命令发送区。**通过标准**为正确命令能执行，查询能返回数据。非法输入期间 VOFA+ 波形仍连续，屏幕保持刷新，`STAT?` 的 `MS` 连续增长，错误和丢包计数没有增加。

### 3. 频率、峰峰值和直流分量

**用到的引脚**为 `PA5 / ADC1_IN5`、`GND`，读数走 TFT 或 USART1。

1. 设正弦波为 1.00 Vpp、1.50 V 偏置，用参考仪表确认实际值。在 **1、2、3、4、5 kHz** 各记录一次屏幕和 `MEAS?` 的数据。
2. 再改变幅值和偏置，例如从 0.20 Vpp、1.00 V 偏置改到 2.00 Vpp、2.00 V 偏置。以参考仪表实际测到的数值计算 `|显示值 − 参考值| ÷ |参考值| × 100%`。
3. **通过标准**为五个频点的频率误差均 ≤3%，Vpp 和直流分量误差均 ≤5%，屏幕和串口均带单位，并在输入变化后 **2 秒内**更新。

### 4. 波形识别

**用到的引脚**为 `PA5`、`GND`，结果显示在 TFT 和 `MEAS?`。

将 **正弦、50% 占空比方波、对称三角波**分别设为 **1、2、5 kHz**。用 1.50 V 偏置，并在安全范围内改变幅值，打乱九组输入顺序。以屏幕和 `MEAS?` 分别显示 `SINE`、`SQUARE`、`TRIANGLE` 为通过。

### 5. TFT 显示、触发对齐和刷新

**用到的引脚**为 `PA5`、`GND` 和上表的 TFT 线。切换触发边沿时再用触摸屏线，或者用 USART1 下命令。

1. 输入 **100 Hz、1 Vpp、1.50 V 偏置、50% 占空比方波**。发 `MODE AUTO`、`TB 2000us`、`TRIG 1.5`、`EDGE RISE`。看上升沿是否固定在触发竖线附近。再切 `EDGE FALL`，看对应的下降沿是否固定。
2. 把方波从 100 Hz 改成约 220 Hz。确认波形在 **1 秒内**重新对齐。观察屏幕网格、横轴时间、纵轴电压、三项测量读数和实际画面是否出现滚动、撕裂或抖动。
3. **通过标准**为触发位置稳定，FPS **≥10**，读数和 `MEAS?` 对得上。`LCDSYNC=1` 且 `LCDMISS` 没有增长可辅助判断写屏情况，最后要看实屏。

### 6. 三种触发模式、时基、垂直档位和游标

**用到的引脚**为 `PA5`、`GND`、TFT 及触摸线。用 USART1 查询 `CONF?`、`STAT?` 可交叉核对。

| 功能 | 现场操作和通过标准 |
|---|---|
| 自动 AUTO | 输入约 1.5 V 的稳定直流，设 `TRIG 3.0`，点 `MODE` 到 `AUTO`。无触发时应看到基线，`STAT?` 的 `FRAME` 仍增长。 |
| 正常 NORM | 先接普通正弦并用 `TRIG 1.5` 抓到一帧，再选 `MODE NORMAL`，把触发改到 3.0 V。上一帧应保留，`FRAME` 停在原帧号，`ADC` 仍增长。将触发调回 1.50 V 应恢复更新。 |
| 单次 SINGLE | 先把阈值放到波形上方，例如 3.0 V，再点 `SINGLE`，确认显示 `ARM`。把阈值调回 1.50 V，应抓到一帧并变为 `STOP`。改变输入，冻结帧应保持。再点 `SINGLE` 可重新武装。 |
| 时基 `TIME` | 回到 `AUTO` 运行态，输入 1 kHz。依次点过 **200、500、1000 µs/格**，理论上 10 格分别显示约 **2、5、10** 个周期。用屏幕或 `CONF?` 确认档位。 |
| 垂直 `V/DIV` | 输入 **0.50 Vpp、1.50 V 偏置**，用触摸切出 **100、250、500 mV/格**，波形分别应占约 **5、2、1 格**。Vpp 读数应仍约为 0.50 V。 |
| 阈值和边沿 | 点 `LEVEL`，在波形区上下拖动。橙色水平线和 `CONF?` 的 `TRIG` 应一起改变。再点 `LEVEL` 退出；用 `EDGE` 切换上升或下降沿并复核触发位置。 |
| 冻结和双游标 | 输入 **1 kHz**，用 **200 µs/格**，波形稳定后点 `CURSORS` 或 `RUN/STOP` 冻结。分别拖两条竖线到相邻周期的同一个上升穿越点，两线应约相隔五格。`dT` 应约 **1000 µs**，`1/dT` 应在 **950～1050 Hz** 内。 |

## 拓展功能逐项测试

### 7. 双通道同时采集、测量和显示

**用到的引脚**为 **P8-29 / PA5**、**P8-32 / PA6**、GND 和 TFT 线。用 `MEAS?` 时还用 `PA9 / PA10`。

1. 用同一台双通道发生器，先给 CH1 1.00 Vpp、CH2 0.50 Vpp，两路均为 1 kHz 正弦、1.50 V 偏置。点 `CH1/2` 或发 `CHAN 2`。应看到两种颜色、两行测量值。逐路改幅度并观察对应读数，验证两路接线顺序。
2. 在 **1、2、3、4、5 kHz** 记录两路读数并与参考值比对。通过标准和单路一样，频率误差 ≤3%，Vpp 和直流分量误差各 ≤5%，两路均可识别波形。
3. 要在 VOFA+ 也同时显示两路，另发 `STREAM 2`，绑定两个通道。双路输出每点 **20 µs**。测完可发 `CHAN 1`、`STREAM 1` 回到单路。

### 8. 两路同频相位差

**用到的引脚**为 `PA5`、`PA6`、`GND` 及 TFT。串口回读用 `PA9 / PA10`。

两路都设为 1.00 Vpp、1.50 V 偏置的正弦，发 `CHAN 2`。在 **1、2、3、4、5 kHz** 分别验证一个已知相位差，例如 CH2 超前 CH1 **45°**，再测一个跨零的点，例如 CH2 滞后 CH1 **10°**，应读作约 **350°**。以 `min(|实测 − 参考|, 360° − |实测 − 参考|)` 算圆周误差，通过标准为 **≤5°**。若发生器的相位符号约定不同，用参考示波器核对哪一路先经过上升穿越点。

### 9. FFT、1～5 次谐波柱图和 THD

**用到的引脚**为 `PA5 / CH1`、`GND`、TFT 及触摸线。`THD?` 走 USART1。

1. 点 `FFT` 或发 `PAGE FFT`，再用 `THD?` 回读。先用纯正弦，第一柱应明显最高。再用可编程发生器叠加 **500 mVpk 基波、100 mVpk 二次、50 mVpk 三次**，加 1.65 V 直流偏置，四、五次设为零。在 **1、2、3、4、5 kHz** 逐点测试。
2. 参考 THD 为 `sqrt(100² + 50²) / 500 ≈ 22.36%`。检查前 3 个柱依次降低，第四、第五柱接近零。屏幕柱值用 Vpk，串口 `A1`～`A5` 用 mVpk。题目要求显示各次幅值和 THD 数值，文档未给该项的数值误差上限，可记录和参考源的差值。
3. 对于只能输出基本波形的发生器，可用 **50% 占空比的方波**检查二、四次较低，三、五次可见。定量核对仍以已知谐波含量的输入为准。点 `FFT` 或发 `PAGE SCOPE` 返回时域。

### 10. 自动量程

**用到的引脚**为 `PA5`、`GND`、TFT 和触摸线。串口检查用 `PA9 / PA10`。

1. 关闭第二路显示，输入 1 kHz 正弦、**1.65 V 偏置**，运行态点 `RANGE` 或发 `RANGE AUTO`。把幅值按 **0.10 → 0.30 → 1.00 → 2.00 → 3.00 → 0.10 Vpp** 改动，每一步等档位稳定后读取 `CONF?` 的 `VDIV`。
2. 通过标准为每一步波形占绘图区高度 **60%～80%**，稳定后档位不反复变。示波器纵向共六格，可按 `Vpp ÷ (6 × 每格电压)` 核对。0.10 Vpp 约为 24 mV/格，3.00 Vpp 约为 714 mV/格，两端都接近 70%。

## 一次上电的最后一轮

实际接入波形后，让 VOFA+ 保持串流，一边点 `TIME`、`V/DIV`、`EDGE`，一边发送合法和非法串口命令，最后依次检查自动、正常、单次、双路和 FFT。看采样与画面是否持续，再用两次 `STAT?` 对比运行时间和丢包计数。正式演示期间遵守一次上电的要求。现场另行要求改采样率时，按 [架构文档的常改项](架构.md#常改项) 操作。
